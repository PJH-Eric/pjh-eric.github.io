## 部署拓撲（做法 A）
- GitHub Pages：大廳＋18 款前端（`npm run build:vite` 產生 `site-dist/`）
- Render（1 個服務）：17 款共用伺服器，`render.yaml` 以 `GAMES_EXCLUDE=bomb-squad` 排除炸彈小隊
- Oracle Cloud VM：炸彈小隊維持原樣（`https://bomb-squad.duckdns.org`，Caddy＋systemd，不休眠）。games.json 的 `externalServer` 讓 build-all 把這個網址注入 bomb-squad 前端（不加 /g/ 前綴）；其他款注入 `<GAME_SERVER_URL>/g/<id>`。也可用環境變數 `GAME_SERVER_URL_BOMB_SQUAD` 覆寫。
- 注意：Oracle 上跑的是 PJH-Eric/bomb-squad 原 repo。all-in-one 內的 bomb-squad 只換了共用 ws.js（協定未變），前端與 Oracle 後端相容；之後若改了炸彈小隊的後端規則，要另外更新 Oracle（SSH 後重跑 setup.sh）。
- 本機測試（啟動遊戲小小島.bat）仍會載入全部 18 款，包含 bomb-squad。
