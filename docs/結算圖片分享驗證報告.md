# 結算圖片分享驗證報告

## 介面與圖片

結算畫面只保留一顆「分享結果」按鈕。按下後才生成圖片並打開彈窗；右上角「×」可關閉，Escape 與背景點擊也可關閉，關閉後焦點回到原按鈕。彈窗內只有 PNG 預覽、「分享圖片」及「下載 PNG」。文字分享、複製文字、網址分享及其他方式均已移除；Web Share payload 只包含 PNG File。

實際水果連連看單機結算（1940 分、6 連擊）產生 1080×1295 PNG。淡紫／藍／暖橘品牌卡保留真實結算資料與乾淨正式網址，未包含 query／hash。已檢視手機、平板直向／橫向與桌機彈窗截圖：

## 驗證

- 18 款原專案與 18 個 all-in-one 複本：專案內分享流程／PNG 測試 74/74 通過（每款各 2 項，射氣球兩邊另含票券測試）。
- 共用來源測試另外 2 項通過，覆蓋單一結算按鈕、懶載入彈窗、只分享 files、取消／下載回退、×／Escape／背景關閉、焦點還原、重新開局及四種尺寸。
- 真實 PNG 像素檢查通過：PNG 簽章、1080px 寬、完整結算與排行尾端、分享控制排除、乾淨網址、Blob 釋放及重試。
- 原版與整合版 snake-3d、ice-duel 四個 Vite build 均成功；all-in-one 靜態與兩款 Vite 聚合建置成功。靜態共用檔同步檢查通過。
- 兩份 cute-game-builder 分享技能參考通過 skill-creator validator。
- 系統分享面板以 API stub 驗證 File payload；未用 stub 宣稱實體手機跨 App 分享已驗收。

## 提交與部署

17 款有 remote 的原專案均已提交、推送，GitHub Pages 工作流程成功，正式分享 helper、語系與圖片 renderer 皆與本機版本 SHA-256 相符。冰壺沒有 remote；all-in-one 也沒有 remote，兩者只保留本機提交與建置。

## 清理

先前已依需求清除 306 個暫存／重複檔案（約 34.5 MiB）。本輪 all-in-one 建置另產生 18 個 Windows Temp 暫存專案（約 305.32 MiB）。已確認這些資料夾都是建置產物，但自動安全審查拒絕遞迴刪除這些 workspace 外的路徑；它們目前仍保留。遊戲程式、測試、報告、建置產物及本機工作副本均未因此刪除或改寫。
