# 結算結果圖片分享實作計畫

狀態：完成（2026-10-30）。18 款原專案與 all-in-one 對應遊戲同步；17 款原專案部署，冰壺與 all-in-one 維持本機。

1. 每個結算視窗只放一顆「分享結果」按鈕。點擊後才開啟圖片彈窗，右上角提供「×」關閉鍵；Escape、點背景也能關閉，關閉後將焦點還給原按鈕。
2. 彈窗只顯示實際結算 PNG 預覽、「分享圖片」與「下載 PNG」。移除文字分享、複製文字、連結分享及其他分享方式。
3. 使用者先點「分享結果」產生 PNG；圖片備妥後，由「分享圖片」按鈕直接呼叫 navigator.share({ files: [file] })，payload 僅含 PNG File。不支援或失敗時保留預覽並提示明確下載；取消不自動下載或切換分享方法。
4. 沿用固定版本、隨站部署的 html2canvas 與各遊戲現有元件；品牌圖片卡保留真實結算、遊戲名稱及乾淨網址，不遮字或截斷排行。
5. 結果更新時清除舊圖片／Blob URL，忽略過期工作；所有語系、鍵盤／觸控及 390×844、768×1024、1024×768、1440×900 版面都要驗證。
6. 原專案與 all-in-one 分別測試、建置、提交。推送有 remote 的原專案，等候 Pages 部署並以正式資產 SHA-256 比對。更新 cute-game-builder 技能。

主要程式碼：packages/web-core/result-share.js、packages/web-core/locales/result-share.js、各專案對應複本與 result-share 測試。射氣球另整合票券按鈕元件。無後端圖片上傳、剪貼簿或社群 SDK。
