# 全遊戲結算分享實作計畫

日期：2026-10-30

**目標**

為 18 款遊戲的所有既有結算畫面增加「分享結果」自訂按鈕。分享目前畫面已公開顯示的勝負、比分、名次或時間，以及乾淨的遊戲入口連結；支援繁中、簡中及英文。原專案分別驗證、提交、推送與部署，並把同一功能同步至 all-in-one，保留整合專案既有的網路層差異。

**影響範圍**

- amaze-go、bomb-squad、draw-guess、flip-match、fruit-link、heart-attack、house-stack、ice-duel、maze-roll、pinball-hoops、pool-duel、rainbow-bubble、reversi、shoot-balloon、snake-3d、stair-kids、sudoku、whack-a-mole。
- 靜態遊戲的 `public/index.html`、`public/js/result-share.js`；動態結算的 `public/js/app.js`、`public/js/game.js`。
- ice-duel 的 `src/screens/game.ts`、`index.html` 與 `public/result-share.js`；snake-3d 的 `client/src/screens/game.jsx`、`client/index.html` 與 `client/public/result-share.js`。
- all-in-one 對應遊戲及 `packages/web-core/result-share.js` 共用來源。
- cute-game-builder skill：將結算分享納入預設結算動作及測試要求。

**實作步驟**

1. 盤點各專案 Git 狀態、結算入口、現行語系與發布 workflow，保留現有未提交變更。階段一先產出本計畫。
2. 實作零相依共用分享元件：只在明確標記的結算容器中掛載；從該容器取得當下可見的結果文字，排除操作按鈕、設定、隱藏內容及分享元件本身。分享前可預覽並手動複製。
3. 優先在按鈕點擊事件內呼叫 Web Share API；使用者取消時保留畫面、不自動複製。裝置不支援或分享失敗時複製結果與連結；剪貼簿不可用時提供可選取的唯讀文字。避免重複點擊、重複掛載與過期非同步回應；返回或再開一局時不影響遊戲與紀錄。
4. 用 `data-result-share` 明確標記各靜態／動態結算內容，避免把暫停、房間關閉、每回合揭曉或房內上一局摘要誤當結算。保留既有再玩、回房、回首頁按鈕。分享入口只出現在結算流程。
5. 分享連結使用目前部署的 origin 與 pathname，移除所有 query/hash，避免帶出房號、token 或觀戰權限。內容僅包含結算公開結果，不讀取聊天、儲存資料或私有狀態；不傳送網路請求或改動統計。
6. 逐款執行既有測試與必要建置；另加分享整合測試，驗證原生分享、取消、複製、權限拒絕、手動複製、語系、重畫及不同結果。以手機、平板直向／橫向、桌機尺寸實際截圖檢查結算與分享元件。
7. 每一連貫實作階段驗證後建立繁中 commit。完成後更新 skill，依 loop-engineering 做有界終驗，每個問題最多三次不同修復；記錄實際通過項目及限制。
8. 依使用者本次「推送部署」授權，逐款推送既有部署分支，追蹤既有 Pages workflow，檢查正式站資產及分享入口。all-in-one 若未設定 remote 則完成本機同步與提交，清楚回報未能推送／部署的原因，不自行建立雲端專案。

**相關程式碼片段**

靜態結算（例如 `fruit-link/public/index.html`）：

```html
<div class="ovcard" data-result-share>
  <!-- 保留既有公開結算資料與操作 -->
</div>
<script defer src="js/result-share.js"></script>
```

動態結算（例如 `ice-duel/src/screens/game.ts`）：

```ts
const body = h('div', { class: 'result-body', attrs: { 'data-result-share': '' } })
```

分享核心：

```js
const url = location.origin + location.pathname;
try {
  await navigator.share({ title, text, url });
} catch (error) {
  if (error.name !== 'AbortError') await copyOrShowText(text + '\n' + url);
}
```

**驗證方式**

- 每款既有規則、語系、紀錄及相關整合測試；Vite 遊戲執行正式建置。
- 分享行為使用瀏覽器 API stub 確認 payload、取消、拒絕與回退；不真的送往社群或聯絡人。
- 每款結算掛載一次、資料隨新一局更新、切換語系不影響對局、原有按鈕可達且可操作。
- 390×844、768×1024、1024×768、1440×900 檢查繁中／英文的結算及分享內容；保留截圖與逐款結果。
- 既有 CI／Pages workflow 完成後檢查正式 URL 與部署 SHA。
- 系統原生分享面板在真實手機的最終送出屬人工裝置驗收；自動化可驗證 API 呼叫與錯誤分支，回報時區分。

**不包含項目**

- SQL script、Migration、後端資料庫、公開戰績榜、圖片產生與第三方社群 SDK。
- 新增部署服務、變更網域、秘密、既有 workflow 或整合專案的發布拓撲。

技術依據：[W3C Web Share API](https://www.w3.org/TR/web-share/)。
