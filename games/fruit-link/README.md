# 水果連連看 🍓🔗🍍

可愛風連連看。兩個一樣的圖案，只要中間存在一條**只走上下左右、只經過空格、轉彎不超過 2 次**的路徑，
就能一起消掉；路徑可以繞到盤面外面那一圈，所以最外圈的圖案不會被困住。

**六種圖案主題**：🍓 蔬果、🐻 動物、🍔 食物、🚩 國旗、🀄 麻將，還有不含麻將的 🎲 大混搭。
其中 🀄 **麻將會以疊牌外觀呈現**：牌像真的麻將一樣一層層疊上去，但每層的遊玩規則各自獨立（見下面的「麻將疊疊樂」）。

- **單機闖關**：幼幼班 → 幼幼進階 → 幼幼困難 → 第一關 → 第二關 → 第三關，分數累加。
- **幼幼班 👶**：專門給 **3～5 歲**小朋友 —— 4 × 3 十二格、只有三種水果、格子很大、
  時間長到幾乎沒有壓力、提示與洗牌不限次數，而且每一顆水果都會寫上名字。
- **幼幼進階 🍌**：5 × 4 二十格、10 種水果，**每一種剛好只有一對、完全不重複** ——
  找到同一種水果就一定是那一對，不用再分辨哪兩顆才是同一組。格子與時間都和幼幼班一樣寬鬆。
- **幼幼困難 🍉**：6 × 5 三十格、15 種水果，一樣**每一種只有一對**。
  盤面再大一點、要多找一下，但規則和幼幼進階完全一樣，格子與時間也還是幼幼班的規格。
- **線上競速**：最多 **6 個人共用同一張盤面**，同一對水果**誰先連到就是誰的分**，
  另有觀戰、邀請連結、聊天室與即時戰況。
- 每一局都會從主題裡**隨機抽**圖案，所以同一關每次玩到的組合都不一樣。
- 手機／平板／桌機、直向橫向都能玩；右上角有設定。

## 最快開始（在自己電腦上玩）

雙擊 **`啟動遊戲.bat`**（第一次會自動 `npm install`），瀏覽器會自己打開
<http://localhost:3040>。

視窗裡會印出「同網段」網址，例如 `http://192.168.1.23:3040` ——
同一個 Wi-Fi 下的手機、平板、其他電腦輸入這個網址就會進到同一個大廳，可以直接開房競速。

指令版：

```bash
npm install
npm start           # http://localhost:3040
```

## 玩法

### 連線規則

| 折數 | 說明 |
|---|---|
| 0 折 | 同一列或同一行，中間一路都是空格 |
| 1 折 | 轉一次彎，轉角必須是空格 |
| 2 折 | 轉兩次彎，常常是繞到盤面外圈那一圈 |
| 3 折以上 | **不算**，連不起來 |

> 盤面內部四周固定多留一圈空白，連線可以繞出去 —— 這是連連看的標準規則，
> 少了它，最外圈的水果常常會變成無解。

### 計分

| 項目 | 分數 |
|---|---|
| 連成一對 | 基礎 **100** 分 |
| 連擊加成 | **5 秒**內接著連下一對，每次 **+10%**，最多 **×2.0** |
| 連錯 | **不扣分**，只把連擊歸零（對小朋友友善） |
| 過關剩餘時間 | 每剩 1 秒 **+2** 分（清空盤面才有） |

### 六種圖案主題

| 主題 | 種類 | 內容 |
|---|---|---|
| 🍓 蔬果 | 60 種 | 水果與蔬菜 |
| 🐻 動物 | 60 種 | 陸海空的動物們 |
| 🍔 食物 | 60 種 | 正餐、點心與飲料 |
| 🚩 國旗 | 72 種 | 各國國旗 |
| 🀄 麻將 | 34 種 | 一副麻將牌；**這個主題會以疊牌外觀呈現** |
| 🎲 大混搭 | 252 種 | 蔬果、動物、食物和國旗混在一起（不含麻將） |

蔬果、動物、食物、國旗與大混搭只改變圖案；麻將則使用下方的分層規則。每一局開場會用種子亂數
從主題裡抽出這一關要用的那幾種（困難關要 30 種，國旗有 72 面可以抽），
所以同一關每次玩到的組合都不一樣；線上則靠同一個種子讓全場抽到同一組。

全部造型都是**向量手繪的寫實風**：參考真實物品的輪廓、顏色與細節（種子、紋路、毛色、花紋），
統一「左上受光、右下陰影、底下接觸陰影」的打光，縮到平板上一格四十幾像素仍然分得出來。
沒有用 emoji 文字 —— emoji 會被作業系統字型影響，換一台裝置就換一種長相；
也沒有用漸層 —— 同一張盤面會貼上幾十份相同的 SVG，漸層要靠 id 參照，重複 id 在消除動畫時會出問題。

**避免誤判**是畫這些圖的第一原則：不畫卡通表情（每一種都變成「一顆有臉的圓球」反而更難分），
容易混淆的刻意拉開距離 —— 蘋果是直立心形、番茄壓扁加五角萼片、甜椒改成黃色的燈籠形；
貓／狗／狐狸／浣熊／老鼠靠耳型、面罩與毛色區分；
裝在容器裡的食物則用不同的容器（紅碗／白碗／玻璃碗／平盤／高杯／金屬鍋）分開。

每一種圖案還會配到一個**專屬色相**的磚塊（同一局裡不會撞色），
磚塊側面那條深色就是最顯眼的顏色標記，圖案之外多一層保險。

### 磚塊

磚塊是一塊有厚度的牌：落地陰影 → 側面 → 正面 → 內斜角（上緣打亮、下緣壓暗）→ 頂部光澤 → 圖案。
格子間距壓到最小、外圈留白只留半格（連線路徑繞得出去就夠了），所以磚塊會盡量放大。

設定裡的「顯示水果名稱」**預設開啟**（麻將牌除外），顯示時**圖案會自動往上縮**，把磚塊正面下緣整條讓給文字，
兩者完全不重疊。名稱擺不擺得下只跟**一格有多大**有關，跟裝置是手機還是平板無關，
所以整組規則都用容器查詢（`.cell` 是 `inline-size` 容器）決定：

| 一格寬度 | 名稱 | 圖案 |
|---|---|---|
| ≥ 56px（平板／桌機的每一關） | 顯示，字級跟著格子走（8～13px） | 縮到 66% 往上讓位 |
| < 56px（手機的入門／日常／大亂） | 不顯示 —— 字會小到 7px、圖案也得縮到一半，兩邊都認不清 | 維持原本大小 |

幼幼班的字級下限是 11px（小朋友要看得清楚），所以讓位的幅度另外算。

### 六個關卡

| 關卡 | 盤面 | 水果種類 | 時間 | 提示 | 洗牌 |
|---|---|---|---|---|---|
| 🍼 幼幼（3～5 歲） | 4 × 3 | 3 種 | 600 秒 | ∞ | ∞ |
| 🍌 幼幼進階 | 5 × 4 | 10 種（每種只有一對） | 600 秒 | ∞ | ∞ |
| 🍉 幼幼困難 | 6 × 5 | 15 種（每種只有一對） | 600 秒 | ∞ | ∞ |
| 🍓 簡單 | 8 × 6 | 12 種 | 240 秒 | 5 次 | 5 次 |
| 🍍 普通 | 10 × 8 | 20 種 | 300 秒 | 3 次 | 3 次 |
| 🥑 困難 | 12 × 10 | 30 種（開始混進蔬菜） | 360 秒 | 2 次 | 2 次 |

平面盤面會讓每種圖案最多出現 **2 對（4 個）**，透過增加種類降低相同水果的重複性，讓畫面更容易辨識。

### 麻將疊疊樂（只有 🀄 麻將主題）

選了麻將主題，盤面外觀像真的麻將一樣**疊起來**，但每一層都視為獨立的平面連連看：

- 牌一層層往上疊，**上面那一層整層往右下偏半張**，所以一張上層牌會壓住下層的 **4 張**（邊角會少一點）。
- 上層蓋住下層的牌會**變暗、點不動**（連 Tab 都跳過），要先把疊在它上面的牌消掉才會解鎖；但其他層不會阻擋本層路徑。
- 麻將也要走 **0／1／2 折**的合法路徑，而且兩張牌必須**同圖案、同層、都沒有被上層蓋住**。
- 提示、洗牌、死局自動洗牌照樣有用；洗牌只換牌面，**位置不會動**。

| 關卡 | 疊法（底層） | 層數 | 總牌數 |
|---|---|---|---|
| 🍼 幼幼 | 4 × 3 | 2 層 | 14 張 |
| 🍌 幼幼進階 | 5 × 4 | 2 層 | 26 張 |
| 🍉 幼幼困難 | 6 × 4 | 2 層 | 32 張 |
| 🍓 簡單 | 8 × 4 | 2 層 | 44 張 |
| 🍍 普通 | 10 × 5 | 3 層 | 80 張 |
| 🥑 困難 | 12 × 6 | 3 層 | 128 張 |

**一定解得完**：發牌會把每層的位置隨機打散後兩兩配對；每一層都是偶數張，
開局必定有同層合法路徑，遇到死局時系統也會自動洗牌，不會卡住。

### 提示、洗牌與死局

- 💡 **提示**：點亮一組還能連的水果。
- 🔀 **洗牌**：把剩下的水果重新排一次，而且**保證重排後一定還有解**。
- 消除之後水果**位置固定不動**，所以偶爾會走到「誰都連不到」的死局 ——
  這時候系統會**自動免費洗牌**，不會浪費玩家的次數。
- 線上競速為了維持公平，**不提供手動提示與洗牌**；遇到死局時仍由伺服器自動重排共用盤面。

### 操作

- **觸控／滑鼠**：點一下選起來，再點第二個送出；點同一個取消；點到不同種水果會直接把選取換過去。
- **鍵盤**：方向鍵移動、Enter／空白鍵選取、Esc 取消。
- **螢幕閱讀器**：每一格都會唸出第幾列第幾行、哪一種水果、有沒有被選起來。
- **左上角兩顆**：◀ 離開這一局、↻ 重新開始（重抽同一關的盤面），都是同一種墨色向量圖示。
  兩顆在打到一半按下去都會先確認一次。線上競速大家共用同一張盤面，所以只有離開。

## 模式

### 單機闖關

從任何一關開始都可以，過關後可以直接接下一關，分數累加。
每一關的最高分、最快時間與最高連擊會存在這台裝置的瀏覽器裡（不會上傳）。

關卡選單分成**幼幼班**（三關）與**闖關模式**（三關）兩區，
每一區各自排滿一整列，卡片上只放盤面、種類、時間與提示／洗牌次數，
「這一區是給誰玩的」寫在區塊標題，不在每張卡上重複一次。

### 線上競速（最多 6 人）

全部人看**同一張盤面**，同一對水果先連到的人得分，慢一步只會撲空（不扣分）。
時間到或盤面被清空就結算，分數最高的人贏。

| | |
|---|---|
| 關卡與圖案 | 由**房主**決定，全場看到的都一樣；對局進行中不能改 |
| 玩家席位 | 最多 6 人；席位滿了或對局進行中進來的人會**先變成觀戰**，下一局才能下場 |
| 觀戰 | 看得到盤面、即時排行與聊天室，但不能出手（權限旗標由伺服器算好才給前端） |
| 邀請連結 | 房主可產生「下場玩／只觀戰」兩種邀請，預設 30 分鐘、最多 5 人用，可隨時撤銷 |
| 提示與洗牌 | 線上競速不提供手動提示與洗牌；死局時由伺服器自動重排共用盤面 |
| 斷線 | 座位保留 60 秒，用同一台裝置重新整理就會回到原位 |
| 房號 | 5 碼，拿掉容易看錯的 0 O 1 I |

## 版面

- **桌機／平板橫向**：左邊一條窄側欄同時放「即時戰況」與「聊天室」，其餘全部留給盤面，
  盤面依可用空間**等比長到最大**。
- **手機／平板直向**：側欄收成從左邊滑出的抽屜（左下角有 📊 與 💬 兩個開關），
  盤面吃滿寬度，即時排行改成盤面上方／左側的浮條（不擋觸控）。
- 每個畫面**右上角**都有 ⚙ 設定：背景音樂與音效**分開**開關與音量、觸控震動、減少動態、
  顯示水果名稱（預設開啟）。設定會記在本機，重新整理還在。

```
│     ├─ rng.js        可注入的種子亂數（同一個種子 = 同一張盤面）
│     ├─ rules.js      規則核心：連線判定、盤面生成、洗牌、計分、造型抽樣（前後端共用）
│     ├─ themes.js     造型主題的登記處（含「大混搭」）
│     ├─ themes/       造型資料：fruits / animals / food / flags / mahjong（純資料，可以一直加）
│     ├─ storage.js    本機偏好與個人紀錄
│     ├─ svgui.js      立體 SVG 按鈕、水果磚、LOGO、獎盃
│     ├─ audio.js      Web Audio 即時合成的音樂與音效（不需要任何音檔）
│     ├─ render.js     盤面、連線動畫、特效、側欄清單
│     ├─ online.js     Socket.IO 連線包裝
│     └─ app.js        畫面流程與輸入
├─ lib/rooms.js        房間、座位、觀戰、邀請、聊天、對局生命週期（只在伺服器跑）
├─ server.js           Express + Socket.IO 權威伺服器
├─ tests/verify.js     規則與房間的單元測試
├─ scripts/
│  ├─ online-check.js  真的開伺服器跑一輪線上流程
│  ├─ browser-check.js 真的開瀏覽器跑 RWD、單機一局與手機鍵盤讓位
│  └─ inject-server-url.js
└─ 啟動遊戲.bat
```

**規則只有一份。** `public/js/rules.js` 同時被瀏覽器（單機）、`server.js`（線上）
與測試 `require`，所以單機和線上不可能長出兩套會漂移的判定。
線上模式前端只送「我點了哪兩格」，能不能連、加幾分、那兩格還在不在，全部由伺服器說了算。

## 部署

### 伺服器（Render 免費方案）

在 Render 選 **New → Blueprint**、指到這個 repo，`render.yaml` 已經寫好了，**不用填任何環境變數**。
部署完成後把服務網址（例如 `https://fruit-link.onrender.com`）記下來，等一下要填到 GitHub。

`GAME_ALLOWED_ORIGIN` 預設 `*`，想收緊就在 Render 的 Environment 改成前端網址。

免費方案的限制已經設計進去了：

- 閒置約 15 分鐘會**休眠**，第一次連線要等十幾秒喚醒 —— 前端 `/health` 的逾時放寬到 10 秒。
- 檔案系統是**暫時的** —— 房間只存在記憶體，不寫任何檔案，服務重啟後房間消失是預期行為。
- 有 CPU／頻寬配額 —— 搶消是**事件驅動**（不是每幀送完整盤面），
  主迴圈只負責「時間到就結算」，空房與打完很久的房間會自動回收。

### 前端（GitHub Pages）

**整套佈署只需要設定一個參數。**

1. Settings → Pages → Build and deployment → Source 選 **GitHub Actions**。
2. Settings → Secrets and variables → Actions → **Variables** → New variable：
   - Name：`GAME_SERVER_URL`
   - Value：上一步 Render 的服務網址，例如 `https://fruit-link.onrender.com`（不要加結尾斜線）
3. 推上 `main`，`.github/workflows/deploy-pages.yml` 會自動把這個值注入
   `public/js/config.js` 再發佈 `public/`。

沒設 `GAME_SERVER_URL` 的話 workflow 會**直接失敗並提示**，不會靜默發佈一個
退回同源（github.io）、看起來能連線但每次都失敗的頁面。

改網址不用改程式：更新 variable 之後在 Actions 頁面按 **Run workflow** 重跑即可；
`Run workflow` 也可以填 `server_url` 臨時覆蓋一次。

**server URL 只有 `public/js/config.js` 這一個入口**，其他檔案不准寫死網址。
解析順序：`?server=` 網址參數 → 建置注入 → 同源 → 都沒有就只能玩單機。
`https` 頁面不接受 `http` 伺服器（瀏覽器會擋混合內容），格式不合會被擋下並停用線上功能，
**不會**靜默回退到 localhost 或任何寫死的網域。

跨電腦臨時測試可以直接用網址參數：

```
https://你的帳號.github.io/fruit-link/?server=https://fruit-link.onrender.com
```

### 環境變數

| 變數 | 預設 | 說明 |
|---|---|---|
| `PORT` | 3040 | 監聽埠（Render 會自動注入） |

## 素材與授權

- 造型是專為這個遊戲畫的寫實風向量 SVG（蔬果 42／動物 42／食物 42 全部手繪，國旗 53 面），
  沒有任何外部素材，也不依賴系統字型。
- 國旗大多是「色帶 + 簡單標誌」，所以用規格產生（`themes/flags.js` 裡的 `bands` / `nordic` / `star` / `crescent`），
  要再加新的國旗只要多寫一行規格。
- 音樂與音效是 Web Audio **即時合成**的，不需要任何音檔，也沒有授權問題。
- 想加新造型：在 `public/js/themes/<主題>.js` 的清單多加一筆就好，規則不用動。
  畫法照著檔案開頭的說明：100×100 viewBox、輪廓 2.4～2.6、底色 + 陰影形狀 + 打亮形狀、
  底下一片接觸陰影；不要用漸層，也不要畫表情。
- 想加新主題：新增一個 `public/js/themes/<名字>.js`，在 `themes.js` 登記，並在 `index.html` 加一行 script。
- 麻將是唯一會影響玩法的主題：`rules.js` 的 `STACK_THEME` 決定哪個主題要疊起來，
  疊法本身（座標、壓住判定、發牌、洗牌）集中在同一個檔案的「疊疊樂盤面」那一段。
- 想換音樂或音效：改 `public/js/audio.js` 的 `SFX` 與 `MEL`。
