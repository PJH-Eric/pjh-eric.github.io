# 房間與線上人員生命週期

## 行為

- 每條連線最多綁定一個房間成員。已在房內時，重複建立、快速加入或加入其他房間回覆 `already_in_room`；必須先離開，不覆蓋連線索引。
- 真人明確離開立即移除；觀戰者斷線立即移除。真人斷線後保留 30 秒重連寬限，斷線期間不計在線人數。
- 重連只允許原成員的 key；不能搶走仍連線的席位，也不能覆蓋目前連線的另一個房間身分。
- 每位斷線成員只持有一個清除計時器。成功重連或移除成員時取消；再次斷線重新計算 30 秒。超過期限即使計時器回呼尚未執行也不能續連。
- 最後一名真人離場或寬限到期後關閉房間。AI、觀戰者不延長存活；撤銷邀請、通知成員，清除成員、連線索引、聊天、對局與計時器。關閉後不可復活。
- 在線人數依實際遊戲連線統計，包含大廳、房內玩家與觀戰者；AI 不算，多分頁各算一條連線。網路異常需先由傳輸層心跳判定斷線。
- 連線增減透過既有大廳通道推送。大廳重連重新訂閱列表與人數，離開線上模式即斷線，不新增輪詢。
- 尚未連線的請求在逾時或退出線上模式時取消，避免稍後才送出過期的建房／加入。晚到的續連回覆不得復活已退出的房間。

## 驗證

```sh
npm run verify
npm run build:pages
# 先啟動開發伺服器；整合站以 BASE 指定完整 /g/house-stack/ 網址
node tests/browser-lifecycle.cjs
```

2026-11-13 在 Node.js 22.23.2 驗證：

- 修正前四個可重現的失敗：重複建房殘留、重複加入關房後新增幽靈成員、續連覆蓋身分、關閉後保留成員／對局物件。
- 回歸測試涵蓋上述情境、反覆斷線的完整寬限、觀戰／AI 清除、邀請失效、大廳重訂閱、晚到回覆與未送出請求取消。
- 實際傳輸層測試涵蓋房間狀態、成員索引及人數推送；完整線上檢查完成一局、再開一局、重連與最後真人離場。
- 瀏覽器確認重連後人數 1 → 2 → 1、首頁無 WebSocket、返回首頁關閉連線。英文大廳及實際房間以手機直橫、平板直橫與桌機五尺寸驗證並截圖，位於 `screenshots/lifecycle/`（不提交產物）。
- 繁中全畫面巡檢涵蓋 320×640、390×844、844×390、820×1180、1180×820、1440×900，包含結算與再玩。獨立版巡檢器對隱藏的自訂聊天室 `.lc-input` 產生 192 筆「未經自訂元件封裝」報告；未修改檢查器或宣稱全數通過。整合站額外以實際房間 selector 驗證進房，避免只檢查大廳就視為房間通過。
- 依 loop-engineering 做兩輪有界檢查：第一輪修正房間索引及計時器；第二輪補齊取消請求、大廳訂閱與整合站路徑問題。保留既有格式，未新增格式化套件，文字使用無 BOM UTF-8。

整合站另保留設定網址中的 `/g/house-stack` 路徑，避免 WebSocket 誤連到站台根目錄，並以設定回歸測試驗證。正式環境、部署後的 Node.js 版本，以及英文其他遊戲畫面未於本次重新全面驗證。
